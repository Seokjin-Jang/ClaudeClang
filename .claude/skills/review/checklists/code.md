# 소스 코드 체크리스트 (SWE.3)

| ID | 항목 |
|---|---|
| COD-01 | 상세 설계와 일치하고, 설계에 없는 동작이 없다. |
| COD-02 | 모든 함수가 반환값을 가진다. (`void` 함수 없음) |
| COD-03 | 모든 함수에서 `return`이 마지막에 한 번만 호출된다. (중간 return 없음) |
| COD-04 | 반환값이 `void` 대신 정상 실행 여부를 판단할 수 있는 값이다. |
| COD-05 | 호출자가 반환값을 확인하고 처리한다. |
| COD-06 | 인터페이스 시그니처가 설계와 동일하다. |
| COD-07 | 내부 함수/변수는 `static` 등으로 숨겨져 있고, 다른 모듈 내부에 직접 접근하지 않는다. |
| COD-08 | 함수가 하나의 책임만 가지며 짧다. 이름이 의도를 드러낸다. |
| COD-09 | 매직 넘버, 중복 코드, 죽은 코드가 없다. |
| COD-10 | 소스에 설계 모듈 ID와 요구사항 ID가 Doxygen 주석으로 연결되어 있다. |
| COD-11 | 프로젝트의 코딩 규칙/정적 분석 결과에 미해결 위반이 없다. |
