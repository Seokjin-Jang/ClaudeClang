# 단위 테스트 체크리스트 (SWE.4)

| ID | 항목 |
|---|---|
| UT-01 | 모든 모듈/함수에 테스트가 있고 상세 설계, 요구사항과 양방향 추적된다. |
| UT-02 | 모든 테스트 함수에 Doxygen 주석(목적, 입력값, 절차, 예상 출력값)이 있다. |
| UT-03 | 케이스가 설계/요구사항에서 도출되었다. (구현 코드에 끼워 맞춘 흔적 없음) |
| UT-04 | 경계값 분석, 동치 클래스가 적용되어 있다. |
| UT-05 | 입력 조합이 많은 경우 PICT 등 조합 기법이 적용되어 있다. |
| UT-06 | 정해진 커버리지 목표가 100% 달성되었고 측정 결과가 기록되어 있다. |
| UT-07 | MC/DC 목표가 있다면 LLVM 보고서로 모든 조건의 독립성이 입증되었다. |
| UT-08 | 무의미한 테스트(단언 없음, 커버리지용 호출)가 없다. |
| UT-09 | Stub/Mock 사용이 최소이며 사유가 타당하다. |
| UT-10 | 예상값이 설계 기준으로 정해졌고, 테스트 결과(통과/실패)가 기록되어 있다. |
| UT-11 | 도달 불가 코드로 인한 미커버 항목은 분석 근거와 함께 처리되었다. |
