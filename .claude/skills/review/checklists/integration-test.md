# 통합 테스트 체크리스트 (SWE.5)

| ID | 항목 |
|---|---|
| IT-01 | 아키텍처의 모든 인터페이스에 테스트가 있고 컴포넌트, 요구사항과 양방향 추적된다. |
| IT-02 | 모든 테스트 함수에 Doxygen 주석(목적, 입력값, 절차, 예상 출력값)이 있고 대상 인터페이스가 명시되어 있다. |
| IT-03 | 인터페이스 정상/경계/무효/오류 경로가 검증된다. |
| IT-04 | 호출 순서, 타이밍, 상태 전이 시나리오가 포함되어 있다. |
| IT-05 | 경계값 분석, 동치 클래스, PICT 조합이 적용되어 있다. |
| IT-06 | 컴포넌트 간 연동 확인이 중심이며 내부 로직 검증으로 치우치지 않는다. |
| IT-07 | 정해진 커버리지 목표가 100% 달성되었고 측정 결과가 기록되어 있다. |
| IT-08 | 무의미한 테스트가 없다. |
| IT-09 | Stub/Mock 사용이 최소이며, 검증 대상 컴포넌트 쌍은 실제 구현으로 연결되어 있다. |
| IT-10 | 테스트 결과(통과/실패)와 환경이 기록되어 있다. |
