# 아키텍처 설계 체크리스트 (SWE.2)

| ID | 항목 |
|---|---|
| ARC-01 | 모든 컴포넌트가 정의되어 있고 책임이 명확하다. |
| ARC-02 | 모든 컴포넌트에 인터페이스가 정의되어 있다. |
| ARC-03 | 인터페이스에 시그니처, 데이터 타입/범위, 호출 순서, 오류 처리가 포함되어 있다. |
| ARC-04 | 컴포넌트 간 통신이 인터페이스를 통해서만 이루어진다. (내부 직접 접근, 공유 전역 변수 없음) |
| ARC-05 | 응집도가 높다. (컴포넌트 책임을 한 문장으로 설명 가능) |
| ARC-06 | 결합도가 낮다. 순환 의존이 없고 의존 방향이 일관된다. |
| ARC-07 | 모듈화와 캡슐화가 지켜진다. |
| ARC-08 | SOLID 원칙을 위반하지 않는다. (위반 시 사유 기록) |
| ARC-09 | 주요 시나리오의 동적 동작이 기술되어 있다. |
| ARC-10 | 모든 요구사항이 컴포넌트에 할당되어 있고, 요구사항 없는 컴포넌트가 없다. |
| ARC-11 | 컴포넌트 <-> 요구사항 <-> 통합 테스트 양방향 추적성이 있다. |
| ARC-12 | 설계 결정의 근거와 제약(자원, 타이밍 등)이 기록되어 있다. |
