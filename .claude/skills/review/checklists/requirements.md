# 요구사항 명세 체크리스트 (SWE.1)

| ID | 항목 |
|---|---|
| REQ-01 | 모든 요구사항에 고유 ID가 있다. |
| REQ-02 | 기능 / 비기능이 구분되어 있다. |
| REQ-03 | 비기능은 품질 / 제한 / 제약사항으로 구분되어 있다. |
| REQ-04 | 품질 요구사항이 ISO 25010 특성에 매핑되어 있다. |
| REQ-05 | 기능 안전 요구사항이 이 문서에 섞여 있지 않고 별도 문서를 참조한다. |
| REQ-06 | 각 요구사항이 원자적이다. (하나의 요구사항에 하나의 내용) |
| REQ-07 | 모호한 표현 없이 검증 가능하게 기술되어 있다. (수치, 조건 명시) |
| REQ-08 | 요구사항 간 충돌, 중복이 없다. |
| REQ-09 | 구현 방법이 아닌 외부에서 관찰 가능한 동작을 기술한다. |
| REQ-10 | 각 요구사항에 우선순위와 검증 방법이 있다. |
| REQ-11 | 상위(시스템) 요구사항과 양방향 추적된다. |
| REQ-12 | 아키텍처 컴포넌트, 테스트와 양방향 추적된다. 연결 없는 요구사항이 없다. |
| REQ-13 | 이전 버전 대비 변경 이력과 영향 분석이 있다. |
