# 상세 설계 체크리스트 (SWE.3)

| ID | 항목 |
|---|---|
| DDS-01 | 모든 컴포넌트가 모듈로 분해되어 있고 모듈 책임이 명확하다. |
| DDS-02 | 인터페이스 정의 대상 기준이 명시되어 있다. |
| DDS-03 | 기준 이상의 모든 모듈에 인터페이스가 정의되어 있다. (시그니처, 범위, 반환값, 선행/후행 조건) |
| DDS-04 | 인터페이스가 있는 모듈은 인터페이스를 통해서만 통신한다. |
| DDS-05 | 모듈과 함수가 단일 책임을 가진다. |
| DDS-06 | 클린코드 원칙(이름, 작은 함수, 중복 없음, 매직 넘버 없음)이 반영되어 있다. |
| DDS-07 | 분기 조건, 경계값, 오류 경로가 기술되어 있어 구현과 테스트 도출이 가능하다. |
| DDS-08 | 모든 함수가 반환값을 가지도록 설계되어 있다. (void 없음, 상태 값 정의) |
| DDS-09 | 아키텍처의 인터페이스와 모순이 없다. |
| DDS-10 | 모듈 <-> 컴포넌트 <-> 요구사항 <-> 소스 <-> 단위 테스트 양방향 추적성이 있다. |
